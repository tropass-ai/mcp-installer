# Tropass MCP

When a task needs Tropass ML models, use the configured Tropass MCP server.

- Refresh `tools/list` only when the tool list is stale or unknown.
- Choose tools by `title`, `description`, and `inputSchema`.
- Validate tool arguments before calling.
- Use existing Tropass/S3 URLs for file inputs.
- Prefer `structuredContent` in tool results.
