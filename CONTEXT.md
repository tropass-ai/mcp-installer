# Tropass Connect

Tropass Connect — интеграция агентских сред с платформой Tropass.

## Language

**Tropass Connect**:
Единая интеграция, через которую агентская среда получает доступ к моделям, инструментам и инструкциям Tropass.
_Avoid_: MCP Installer, Agent Kit

**Агентская среда**:
Приложение, в котором агент использует подключённые возможности Tropass.
_Avoid_: MCP-клиент
